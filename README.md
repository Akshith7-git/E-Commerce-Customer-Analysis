# 🛒 E-Commerce Customer Analysis

## 📌 Project Overview

E-Commerce Customer Analysis is a Data Analytics project developed to analyze customer purchasing behavior and identify meaningful business insights from e-commerce transaction data.

The project focuses on understanding customer preferences, spending patterns, purchase frequency, product performance, category-wise sales, and monthly revenue trends.

Python, SQL, and Power BI are used to transform transaction data into meaningful insights that support data-driven business decisions.

## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Identify top-performing products and categories.
- Understand customer spending patterns.
- Analyze monthly sales and revenue trends.
- Identify customer preferences and purchase frequency.
- Generate actionable business insights.

## 📊 Dataset Information

The project uses a synthetically generated e-commerce transaction dataset.

- **Total Records:** 1,200
- **Total Columns:** 14
- **Time Period:** January – December 2025
- **Customers:** 300
- **Products:** 12
- **Cities:** 8
- **Payment Methods:** 5

### Dataset Columns

- Customer_ID
- Customer_Age
- Gender
- City
- Order_ID
- Order_Date
- Product_ID
- Product_Name
- Category
- Quantity
- Unit_Price_INR
- Discount_Percent
- Total_Amount_INR
- Payment_Method

## ⚙️ Project Workflow

1. **Data Collection:** Obtain e-commerce transaction data.
2. **Data Preprocessing:** Clean and prepare the dataset using Python and Pandas.
3. **Data Analysis:** Analyze customer behavior, sales, products, and revenue.
4. **SQL Analysis:** Perform queries to extract business insights.
5. **Data Visualization:** Generate charts using Matplotlib and Seaborn.
6. **Dashboard Development:** Use Power BI for business intelligence visualization.
7. **Business Insights:** Identify meaningful patterns to support decision-making.
